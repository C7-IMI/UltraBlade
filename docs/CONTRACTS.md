## Arena — `game/scripts/arena_builder.gd` (+ `game/shaders/arena_*.gdshader`)

`class_name ArenaBuilder extends RefCounted`

```gdscript
static func build(parent: Node3D) -> Dictionary
```

Builds the complete drome under `parent` (clears previously generated children named `Drome`).
Returns:

```gdscript
{
  "root": Node3D,                 # generated visual root ("Drome")
  "player_goal": Area3D,          # blue goal at z = -30.5 (player defends); group "goal_blue"
  "enemy_goal": Area3D,           # red goal at z = +30.5; group "goal_red"
  "spawn_blue": Array[Transform3D],  # at least 2 outfield spawns + goalie
  "spawn_red": Array[Transform3D],
  "center_spawn": Transform3D,
  "boost_pads": Array[Node3D],    # metadata "team" optional
  "hazards": Array[Node3D],
  "killball_charger": Area3D,     # group "killball_charger"
  "bounds": { "half_width": 16.0, "half_length": 30.0 },
}
```

Arena dimensions: **x (width) ∈ [-16, 16], z (length) ∈ [-31, 31]**. Goal mouths are cut into
the end walls: width 9 m, centered, goal area from z=±30 to z=±33. Floor at y=0, low boards
0.9 m high. Spawns: blue at z ≈ -19, red at z ≈ +19, goalies at z ≈ ∓27.

Hazard nodes handle their own damage by checking bodies in group `"skater"` and calling
`take_damage(amount, source_position)` if the method exists. Boost pads should have a method
or Area3D that the Lead can query; simply expose the nodes and the Lead applies the effect.
The arena must add colliders for boards, goal posts and obstacles, but must not add a floor
collision if the Lead adds one — document this in your final message.

Use only primitives/procedural meshes and shaders; no external art downloads. Performance target:
< 400 total draw calls, < 60k triangles. It must look intentional in a 1600×900 capture.


States: `idle`, `skate`, `sprint`, `slash`, `heavy`, `hit`, `down`, `celebrate`, `goalie`.

approach: instantiate the rig, add an AnimationPlayer under the model root, duplicate each clip's
Animation resource into an AnimationLibrary (tracks are already `Armature/Skeleton3D:...`), then play
state names. Do not change the imported asset files. Tint the mannequin materials team colour and add
procedural armour/helmet/jak prop meshes so it reads as a hockey gladiator, not a mannequin.
Root position of the visual is at the skater's feet. Scale should read ~1.9 m tall.

Deliver a screenshot/capture path and say exactly which clips were used. The Lead instantiates
`SkaterModel` under each `CharacterBody3D`.
