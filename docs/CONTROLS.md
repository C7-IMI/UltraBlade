# Controls (PC)

| Input | Action |
| --- | --- |
| W A S D | Skate (camera-relative) |
| Mouse | Look / aim |
| Left mouse, no rok | Slash — short range, strips the rok |
| Left mouse, with rok | Hold to charge a shot; release to fire |
| Right mouse | Heavy slash — high damage, long recovery, drops the rok |
| Shift | Boost / speedburst; drains stamina; body-checks on contact |
| Space | Jump (clears laser hurdles) |
| E | Pass to your AI teammate |
| Q | Throw a charged killball at the nearest opponent |
| M | Mute/unmute |
| Esc | Pause / resume; from the end screen, back to the title |
| R | Restart from pause or end screen |
| Enter | Start from the title; rematch from the end screen |

Menu: mouse is visible. Field manual opens from the title screen. Gamepad support is not in this
slice.

## Match rules

- Blue **ICE SAINTS** vs Red **REDLINE SYNDICATE**
- 3 periods × 90 seconds; clock stops during goal sequences
- 2 outfield skaters + 1 invulnerable goalie per side
- A goal is 1 point. The killball is a charged rok that deals heavy damage on contact.
- Downed skaters are removed until the next goal/period; their reserve takes the slot
- Kill both enemy forwards and score to win instantly by **ANNIHILATION**
- Tie after regulation → 45-second sudden-death overtime
